## Intruções de instalação

1. Instale as depências listadas no arquivo requirements.txt
2. No arquivo _main.py_, escolha a linha de código que se adequa ao ambiente que você irá rodar o software
3. No arquivo _apiMercadoPago.py_ adicione o seu token do MercadoPago e atualize as back_urls, para a sua url, seja localhost ou endereço público
3. Se não for utilizar o Pycharm, exclua a linha de codigo "EXPOSE 5000" no arquivo _Dockerfile_

### OBS: as back_urls devem ser https
